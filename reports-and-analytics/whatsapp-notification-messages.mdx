> **Who can use this?**
>
> * Gallabox users with Analytics access and at least one connected WhatsApp channel.

Use WhatsApp Notification Messages when you need recent message logs filtered to notification context.

## Plan Availability

This report has no separate frontend plan gate. It appears according to your Analytics permission and WhatsApp channel access.

## Review Notification Messages

1. Open **Analytics**.
2. Select **WA Notification Message**.
3. Search for and select one or more WhatsApp channels.
4. Review the message ID, content, recipient, date and time, status, remarks, channel, and sender.

The report shows up to the latest 50 matching message logs from the last 15 days.

## Example

**Scenario:** Your operations team wants to confirm whether recent notification messages reached customers.

1. Select the WhatsApp number used for notifications.
2. Locate the relevant recipient and date.
3. Check **Status** and **Remarks**.
4. Use the message ID when investigating an individual send.

## FAQs

<AccordionGroup>
<Accordion title="Why is an older notification missing?">
The screen shows the latest 50 message logs from the last 15 days. Generate a message report when you need a wider period.
</Accordion>

<Accordion title="Is this the same as WhatsApp Failed Messages?">
No. This screen filters messages by notification context and shows their status. WhatsApp Failed Messages filters for failed and error states.
</Accordion>

<Accordion title="Can I review several WhatsApp numbers together?">
Yes. Add each channel to the channel selection.
</Accordion>
</AccordionGroup>
