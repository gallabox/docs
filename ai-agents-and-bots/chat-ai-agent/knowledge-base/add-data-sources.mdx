> **Who can use this?**
>
> * Owners and Admins, and roles that can update AI agents.
> * File uploads: Essential and Advanced. Website URLs: Advanced only.

Add files (and, on Advanced, web pages) to a Knowledge Base. Gallabox processes them after you upload. That uses AI credits. Check status until it shows **Completed**.

## Plan Availability

| Data source | Basic | Essential | Advanced |
| ----------- | :---: | :-------: | :------: |
| Files       |  No   |    Yes    |   Yes    |
| URL         |  No   |    No     |   Yes    |

See [Knowledge Base](/ai-agents-and-bots/chat-ai-agent/knowledge-base/overview#plan-availability) for storage limits.

## What you can add

| Data source            | Format           | Max size per file | Notes |
| ---------------------- | ---------------- | ----------------- | ----- |
| PDF                    | .pdf             | 15 MB             | Text-based PDFs only. Scanned images fail |
| Word                   | .docx            | 15 MB             | |
| CSV                    | .csv             | 15 MB             | UTF-8 |
| Excel                  | .xlsx            | 15 MB             | |
| Text / Markdown / JSON | .txt, .md, .json | 15 MB             | |
| URL                    | web page        | n/a               | Advanced. Gallabox finds pages and extracts text |

Total Knowledge Base storage: **10 MB** on Essential, **100 MB** on Advanced.

Leave chunk settings at the defaults unless answers feel too narrow or too vague.

## How to add a PDF

<Steps>

<Step title="Open Knowledge Base">
Go to **Settings → AI → Knowledge Base**.
</Step>

<Step title="Open or create a Knowledge Base">
Open the library you want to fill.
</Step>

<Step title="Upload the PDF">
Add the file. Drag and drop, or browse.
</Step>

<Step title="Wait for Completed">
Status goes **Pending → Processing → Completed**.
</Step>

</Steps>

**PDF tips:**

* Use a text PDF, not a scan.
* Drop cover pages and legal filler before you upload.
* Clear headings produce better answers.

## How to add a CSV or Excel file

<Steps>

<Step title="Open the Knowledge Base">
Go to **Settings → AI → Knowledge Base**, then open the library.
</Step>

<Step title="Upload the spreadsheet">
Add the .csv or .xlsx file.
</Step>

<Step title="Map columns if asked">
* **Text column:** what the agent should search (product description, FAQ answer).
* **Other columns:** extra context (name, price, category).
</Step>

<Step title="Wait for Completed">
Do not attach the library to an agent until status is **Completed**.
</Step>

</Steps>

**Spreadsheet tips:**

* Put the main text in the first column when you can.
* For a catalog, search `product_description` and keep name, price, and category as extra columns.

## How to add a URL (Advanced)

<Steps>

<Step title="Open the Knowledge Base">
Go to **Settings → AI → Knowledge Base**, then open the library.
</Step>

<Step title="Add a website URL">
Enter the page. Gallabox uses the sitemap if it can, or follows links on the site.
</Step>

<Step title="Review the pages">
Pick the pages you actually want. Do not add the whole site if you only need FAQs.
</Step>

<Step title="Confirm and wait">
Confirm, then wait for **Completed**.
</Step>

</Steps>

**URL tips:**

* Start with your FAQ or help centre.
* Extra pages add noise and use more AI credits.

## How to check status

1. Go to **Settings → AI → Knowledge Base** and open the library.
2. Read each source:
   * **Pending:** waiting
   * **Processing:** in progress
   * **Completed:** ready
   * **Failed:** open the error, then retry
3. Click **Retry** on a failed source.

## How to re-index a document

<Steps>

<Step title="Open the document">
Go to **Settings → AI → Knowledge Base**, then find the file or URL.
</Step>

<Step title="Refresh">
Click the refresh icon next to it.
</Step>

<Step title="Upload the new file if needed">
Or confirm the updated URL.
</Step>

<Step title="Wait for Completed">
Re-indexing uses AI credits. Do it when prices, policies, or product details change.
</Step>

</Steps>

## Example

You have a 50-page product manual as a text PDF.

1. Open the PDF in a browser. Confirm you can select the text (not a scan).
2. Go to **Settings → AI → Knowledge Base**, open your library, and upload the PDF.
3. Keep chunk defaults.
4. Wait for **Completed**.
5. Attach the library on the agent's **Knowledge** tab.
6. Test with "How do I connect the API?" and "What's the minimum system requirement?"

## FAQs

<AccordionGroup>
<Accordion title="My PDF says Failed">
Common causes:

* It is a scan, not selectable text
* It is password-protected
* The file is damaged (try opening it in a browser)
* The file is over 15 MB. Split it

Convert a scan with OCR (Adobe Acrobat or Google Docs) before you upload.
</Accordion>

<Accordion title="How many AI credits does indexing use?">
It depends on how much text is in the files. See [AI Wallet](/pricing-and-billing/ai-wallet).
</Accordion>

<Accordion title="Can I crawl an entire website?">
You can add many pages, but you should not. Pick the pages that answer real questions. A huge crawl takes longer, costs more credits, and can make answers worse.
</Accordion>

<Accordion title="How do I know the agent is using the Knowledge Base?">
Ask a question that only your documents can answer. If the reply cites those details, it is working. If the reply is generic, check: (1) status is **Completed**, (2) the library is attached on the agent's **Knowledge** tab, (3) the question uses the same words as the document.
</Accordion>
</AccordionGroup>
