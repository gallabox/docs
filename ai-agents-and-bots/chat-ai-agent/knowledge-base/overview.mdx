> **Who can use this?**
>
> * Owners and Admins, and roles that can update AI agents.
> * Knowledge Base needs Essential or Advanced. Basic Chat AI Agents on Web Chat cannot use it.

The Knowledge Base is the file library the agent looks up before it answers. Upload FAQs, price lists, and policies. When a customer asks a question, the agent searches those files and answers from what it finds, instead of guessing.

<Info>

Create and fill Knowledge Bases under **Settings → AI → Knowledge Base**. Then attach them to an agent on the agent's **Knowledge** tab. You can attach up to **3** per agent.

</Info>

## Plan Availability

| Capability                | Basic | Essential | Advanced |
| ------------------------- | :---: | :-------: | :------: |
| Knowledge Base total size |  No   |   10 MB   |  100 MB  |
| File uploads              |  No   |    Yes    |   Yes    |
| Website URL crawl         |  No   |    No     |   Yes    |

Essential file types: PDF, Word (.docx), CSV, Excel (.xlsx), text, Markdown, JSON.

Advanced adds website URLs.

Each file can be up to **15 MB**.

## How it works

1. You upload files (or, on Advanced, add page URLs).
2. Gallabox processes them. Status moves from **Pending** to **Processing** to **Completed**.
3. During a chat, the agent searches those files and uses the matching passages in its answer.

If the files do not contain the answer, the agent will still try to reply from its Role, Goal, and Instructions. Tell it what to do when it does not know. Example: _"If you cannot find it in the Knowledge Base, say you don't know and offer to connect them with the team."_

## Connect a Knowledge Base to an agent

<Steps>

<Step>
Go to **Settings → AI → Knowledge Base** and create a Knowledge Base if you do not have one.
</Step>

<Step>
Add files (and URLs on Advanced). Wait until status is **Completed**. See [Add Data Sources](/ai-agents-and-bots/chat-ai-agent/knowledge-base/add-data-sources).
</Step>

<Step>
Go to **AI Agents and Bots**, open the Chat AI Agent, then open the **Knowledge** tab.
</Step>

<Step>
Select up to 3 Knowledge Bases and save.
</Step>

</Steps>

<Check>

Start with the 10 questions customers ask most. Upload the documents that answer those. Add more later. Clear headings produce better answers than a wall of text.

</Check>

## Example

You want the agent to answer pricing, features, and integrations.

<Steps>

<Step>
Create a Chat AI Agent with use case **FAQ**.
</Step>

<Step>
Go to **Settings → AI → Knowledge Base**. Create a Knowledge Base and upload your pricing PDF, a features CSV, and (on Advanced) your FAQ page URL.
</Step>

<Step>
Wait until each source shows **Completed**.
</Step>

<Step>
Open the agent → **Knowledge** tab. Attach that Knowledge Base.
</Step>

<Step>
On **Home**, add: _"Use the Knowledge Base for pricing, feature, and integration questions. If you cannot find the answer, say you don't know and offer to connect them with sales."_
</Step>

<Step>
Test. WhatsApp and Instagram: **Test Widget**. Web Chat: widget preview on **Web Widget**. Ask "What's your pricing?" and "Do you integrate with HubSpot?"
</Step>

</Steps>

## FAQs

<AccordionGroup>
<Accordion title="How many Knowledge Bases can I connect to one agent?">
Up to **3**. Use that if you want product docs in one library, policies in another, and pricing in a third.
</Accordion>

<Accordion title="How long does indexing take?">
Small PDFs (under 10 pages): about 1 to 5 minutes. Large PDFs (over 50 pages): about 10 to 30 minutes. A website crawl depends on how many pages you add. Watch the status: Pending → Processing → Completed.
</Accordion>

<Accordion title="Can I update one file without redoing everything?">
Yes. Open that document in **Settings → AI → Knowledge Base** and re-index it. Other files stay as they are.
</Accordion>

<Accordion title="What if the Knowledge Base does not have the answer?">
Write it into Instructions. Example: _"If you cannot find the answer, say: 'I don't have that yet. Let me connect you with our team.'"_ Then use @assignTo on WhatsApp or Instagram. For Web Chat, use a [WhatsApp handoff](/web-chat/website-analytics#handoff-to-whatsapp).
</Accordion>
</AccordionGroup>
