> **Who can use this?**
>
> * Anyone who has [connected an AI assistant to Gallabox](/mcp/overview).
> * The assistant can only do what the API key you chose allows. A **Read only** key gets the **Read** actions only.

<Info>

Your assistant does these actions only when you ask. **Read** actions look things up. **Change** actions add, edit, send, or delete something in your account.

</Info>

## AI agents

| What you can ask | Type |
| ---------------- | :--: |
| List your AI agents, or view one's full setup | Read |

| Create or update a custom agent action | Change |
| Delete a custom agent action | Change |
| Publish an agent to the channels you choose | Change |

<Warning>

Publishing is the one action that reaches your customers. The agent starts replying on the channels you choose and replaces any agent that was handling them. There's no undo.

Before you say yes, make sure you have seen the agent's role, goal, instructions, and settings in full, the actions it can use, and the channels it will replace. Your assistant is instructed to show you all of this first.

Publishing runs in the background. The assistant tells you it has started, then checks before it tells you the agent is live.
</Warning>

## FAQs

<AccordionGroup>

<Accordion title="Why doesn't my assistant offer actions that send or change things?">
The API key you connected with is **Read only**. A **Read only** key gives the assistant the **Read** actions only. To use **Change** actions, connect again with a key that has **All** access, or a **Restricted** key that includes those permissions. See [Permission scopes explained](/settings/api-keys#permission-scopes-explained).
</Accordion>

<Accordion title="Which actions can't be undone?">
Deleting a contact, a webhook, or a custom agent action is permanent. Publishing an AI agent can't be undone either. An account owner can restore a teammate you remove.

Deleting a segment or an uploaded file is also a delete, so check before you confirm it.
</Accordion>

</AccordionGroup>
