### Data Security Controls

Gallabox follows industry-standard security practices to ensure the protection of customer data. We have implemented multi-layered security controls across four key areas:

#### Predict (Proactive Risk Assessment & Monitoring) 

✅ Penetration Testing – Periodic tests to identify vulnerabilities in applications & infrastructure \
✅ Security Audits – Annual audits for compliance, we are in-process of getting SOC 2 and GDPR compliant

**In-Progress:**

✅ Risk Assessments – Regular security risk assessments & threat modeling

---

#### Prevent (Prevention of Security Incidents) 

✅ Access Control – Role-Based Access Control (RBAC) & Least Privilege Principle \
✅ Multi-Factor Authentication (MFA) – Enforced for all user accounts  \
✅ Data Encryption – AES-256 encryption for data at rest, TLS 1.2/1.3 for data in transit  \
✅ Firewall & Network Security – Cloud-based Web Application Firewall (WAF) and VPN restrictions  \
✅ Secure Software Development (DevSecOps) – Code security reviews, secure API practices, and CI/CD security integration

---

#### Detect (Real-Time Threat Monitoring & Logging) 

✅ Security Information and Event Management (SIEM) – Logs all security events for anomaly detection  \
✅ Endpoint Detection & Response (EDR) – Protects against malware & insider threats

In-process

✅ Intrusion Detection System (IDS) – Monitors network traffic for suspicious activity  \
✅ Cloud Security Monitoring – Continuous monitoring of cloud workloads for unauthorized access  \
✅ Automated Log Analysis – Real-time alerts for potential data breaches or security violations

---

#### Correct (Incident Response & Recovery Mechanisms) 

✅ Incident Response Plan (IRP) – 24/7 security team for rapid incident response  \
✅ Data Backup & Disaster Recovery – Regular backups with geo-redundant storage for data integrity\
✅ Forensic Investigations – Root cause analysis for security incidents, followed by corrective action

In-progress:

✅ Automated Threat Mitigation – AI-driven security response to mitigate risks in real-time  \
✅ Breach Notification Policy – Any security breach is reported within 48 hours per GDPR guidelines

---

In summary, Gallabox is fortified with a multi-faceted approach to data security, encompassing robust infrastructure, stringent access controls, comprehensive encryption, and proactive auditing and recovery measures. These practices collectively ensure the security and integrity of our client's data, making our solution a reliable and trusted choice in the market.
