> **Who can use this?**
>
> * Gallabox users who need to send call data to external systems, such as a CRM or a data warehouse.
> * Roles: Owners and Admins. Custom Roles with the "Can view and manage webhooks, API keys" permission (Developer modules) can also configure webhooks.
> * Plans: Advanced plan and some legacy plans, on accounts with WhatsApp Calling.

> **Note:** This page covers only the call events. For how webhooks work in general — setting one up, verifying the signature, and reading the logs — see [Webhooks](/settings/webhooks).

### What Are Call Webhooks?

Call webhooks tell your system the moment something happens on a call — when it rings, connects, ends, or is missed. Use them to:

* Log every call against the contact's record in your CRM.
* Alert your team when a call is missed.
* Send call data to a data warehouse for your own reporting.

You set them up in the same place as every other webhook: **Settings → Webhooks → Add Webhook**, then select the **Call** events you want.

### Call Events

| Event            | When it fires                                                                                                                                                                                  |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Call.Received`  | An incoming call starts ringing for your business.                                                                                                                                             |
| `Call.Initiated` | Your team places an outgoing call to a customer.                                                                                                                                               |
| `Call.Connected` | The call is answered and both sides are connected.                                                                                                                                             |
| `Call.Ended`     | A connected call ends.                                                                                                                                                                         |
| `Call.Missed`    | A call ends without being answered.                                                                                                                                                            |
| `Call.Rejected`  | The call is declined.                                                                                                                                                                          |
| `Call.Failed`    | The call couldn't connect because of an error.                                                                                                                                                 |
| `Call.Analysed`  | After a call, once its recording is ready. For calls answered by a Voice AI Agent, it fires after the AI has also analysed the call, and includes the summary, goal result and extracted data. |

A single call sends several events over its life. For example, an answered incoming call sends `Call.Received` → `Call.Connected` → `Call.Ended`, and then `Call.Analysed` once the call has been processed. Use the `callId` field to link all events from the same call.

### What Does a Call Webhook Send?

Every call event sends the same set of fields, so one receiver can handle all of them. The event name is sent in the `x-event-name` header, and the call data is in the request body.

The sample below is a `Call.Analysed` event for an incoming WhatsApp call answered by a Voice AI Agent:

```text

```

### Payload Fields

**Sent with every call event:**

| Field                | What it contains                                                                                                                                                                         |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `accountId`          | Your Gallabox account ID.                                                                                                                                                                |
| `channelType`        | The channel the call came through — for example, `whatsapp`.                                                                                                                             |
| `channelId`          | The ID of the WhatsApp number that made or received the call.                                                                                                                            |
| `direction`          | `incoming` (the customer called you) or `outgoing` (your team called the customer).                                                                                                      |
| `callId`             | The unique ID of the call. The same for every event from one call.                                                                                                                       |
| `status`             | The call's status when the event fired — for example, `ringing`, `connected`, `ended`, or `missed`.                                                                                      |
| `statusReason`       | Why the call ended the way it did — for example, why it was missed or failed. `null` if there's no reason.                                                                               |
| `handledBy.type`     | `agent` for a human agent, or `bot` for an AI agent.                                                                                                                                     |
| `handledBy.answered` | `true` if the call was answered.                                                                                                                                                         |
| `handledBy.id`       | The ID of the agent or AI agent the call was assigned to.                                                                                                                                |
| `handledBy.name`     | The name of the agent or AI agent.                                                                                                                                                       |
| `fromNumber`         | The number the call came from.                                                                                                                                                           |
| `toNumber`           | The number the call went to.                                                                                                                                                             |
| `contact`            | The contact's ID, name, phone numbers, and WhatsApp details.                                                                                                                             |
| `conversationId`     | The ID of the conversation the call belongs to.                                                                                                                                          |
| `rungAt`             | When the call started ringing.                                                                                                                                                           |
| `startedAt`          | When the call was answered. `null` if it was never answered.                                                                                                                             |
| `endedAt`            | When the call ended. `null` while the call is still in progress.                                                                                                                         |
| `durationSeconds`    | Talk time in seconds. `0` if the call was never answered.                                                                                                                                |
| `origin`             | For outgoing WhatsApp calls, what made the call possible: `template` (a call permission template) or `call_button` (a call button message), with the related `messageId`. `null` for incoming calls. |

**Sent only with `Call.Analysed`:**

| Field                                             | What it contains                                                                                                                                       |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `recordingUrl`                                    | A link to the call recording. `null` if the recording wasn't ready in time.                                                                            |
| `agentAnalysis`                                   | The Voice AI Agent's analysis of the call. `null` for calls handled by your team.                                                                      |
| `agentAnalysis.botId` / `flowId` / `botSessionId` | The IDs of the Voice AI Agent, the flow it ran, and the session for this call.                                                                         |
| `agentAnalysis.medium`                            | Always `voice` for calls.                                                                                                                              |
| `agentAnalysis.analysisStatus`                    | `completed` if the analysis finished, or `failed` if it couldn't be completed.                                                                         |
| `agentAnalysis.summary`                           | `whatHappened` (a short recap of the call), `keyDetails` (the important details the customer shared) and `nextStep` (a suggested follow-up).           |
| `agentAnalysis.sessionGoal`                       | Whether the agent reached the goal you set for it: `result` is `true` or `false`, and `reason` explains why.                                           |
| `agentAnalysis.extractedData`                     | The data points you asked the agent to collect, such as whether an appointment was booked. The keys match the fields you set up on the agent.          |
| `agentAnalysis.outcomeEvaluations`                | Each outcome you evaluate, keyed by its name, with a `result` (or `value`) and a `reason`.                                                             |
| `agentAnalysis.modelInfo`                         | The AI models used on the call. A field is `null` when that model wasn't used separately.                                                              |
| `conversationAssignee`                            | Who owns the conversation when the event is sent: `type` (`user` or `bot`), `id` and `name`, plus `email` for users. `null` if the conversation isn't assigned. |

All times are in UTC, in ISO 8601 format.

### Quick Reference

| Question                                                  | Answer                                                                  |
| --------------------------------------------------------- | ----------------------------------------------------------------------- |
| Where do I set up call webhooks?                          | **Settings → Webhooks → Add Webhook**, then select the **Call** events. |
| How do I know which event I received?                     | Read the `x-event-name` header.                                         |
| How do I link events from the same call?                  | Use the `callId` field — it's the same on every event for one call.     |
| Which event carries the recording?                        | `Call.Analysed`. It's sent after the call, once the recording is ready. |
| Where do I get the AI agent's summary and extracted data? | In `agentAnalysis` on the `Call.Analysed` event.                        |
| How do I know who owns the conversation after an AI call? | Check `conversationAssignee` on the `Call.Analysed` event.              |
| How do I tell a human-handled call from an AI one?        | Check `handledBy.type` — `agent` for a human, `bot` for an AI agent.    |
| Where can I check if a call webhook was delivered?        | **Settings → Webhooks → Logs**.                                         |
