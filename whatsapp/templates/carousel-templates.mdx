> **Who can use this?**
>
> * Owners, Admins, and roles with WhatsApp Templates access.
> * Needs a **Cloud API** WhatsApp channel. On-Premise channels cannot use this type.

Use **Carousel** when you have several comparable things and the customer should pick one: a product range, plan tiers, or a set of packages.

In **Category**, pick **Carousel**. It is billed as Marketing on every send. See [Message Credits](/pricing-and-billing/message-credits).

Do not use Carousel for a single offer. Use [Custom marketing](/whatsapp/templates/custom-marketing). Do not use it for live catalogue items. Use [Product marketing](/whatsapp/templates/product-marketing).

Cards render on mobile WhatsApp and on WhatsApp Web. There is no footer on this type.

## Plan Availability

Available on all Gallabox plans. Needs a Cloud API channel.

## Create the template

1. Go to **WhatsApp → Templates** and click **Create New Template**.
2. In **Category**, pick **Carousel**.
3. Enter a **Template name**. Gallabox lowercases letters and turns anything else into an underscore. Maximum 60 characters. You cannot change the name after you submit.
4. Choose the **Channel** and **Language**.
5. Write the opening **Message body**, set the carousel type and buttons, add the cards, then click **Submit for approval**.

If the editor says the template is not supported for this channel, see the FAQ below.

To duplicate or test after approval, see [Manage templates](/whatsapp/templates/manage-templates#after-approval).

### Opening message

The **Message body** is the single line above the cards. Say what the set is, and what you want the customer to do.

### Carousel format

This sets the shape every card follows.

* **Carousel type:** **Image Carousel** or **Video Carousel**. All cards use this type. You cannot mix images and videos.
* **Button types:** up to two per card. Button 1 defaults to **Quick Reply**. Each button can be **Quick Reply**, **URL**, or **Phone Number**.

### Cards

Click **+ Add Carousel Card** for each card. Repeat up to 10 times.

Every card needs a media header, body text, and at least one button.

| Limit | Value |
| --- | --- |
| Cards per template | Up to 10 |
| Buttons per card | Up to 2 |
| Image files | `.jpeg`, `.jpg`, `.png` up to 5 MB |
| Video files | `.mp4`, `.3gpp` up to 10 MB |

Every card must share the same media type and the same button layout, in the same order. You can change the text, the destination, and the media file. You cannot change the shape.

If card 1 has an image and two buttons (one Quick Reply, one URL), every other card needs an image and those same two button types.

For every card, fill:

1. **Card header:** the image or video, within the size limits.
2. **Card body:** the text for this card. An empty body is the most common validation error. Gallabox flags that card.
3. **Button text:** the label for each button you set above, plus the URL or phone number.

## Send it

After **Approved**, send it from a broadcast, a sequence, the inbox, or a bot. See [After approval](/whatsapp/templates/manage-templates#after-approval).

Variables work per card. When you send, fill card-level placeholders alongside the opening message.

## FAQs

<AccordionGroup>
<Accordion title="Carousel is not available when I create a template.">
The number you picked is not on Cloud API. The editor shows **Carousel template is not supported for this channel**. Use **Raise a ticket** under that warning, or talk to support about moving the number.
</Accordion>
<Accordion title="Can I mix images and videos across cards?">
No. You choose Image Carousel or Video Carousel for the whole template. Every card follows it.
</Accordion>
<Accordion title="Can different cards have different button types?">
No. Button types and their order must match across cards. Button text and destination can differ.
</Accordion>
<Accordion title="My carousel template was rejected. Why?">
Check card uniformity first. Mismatched media types or button layouts are the usual cause. For other Meta reasons, see [Why was my template rejected?](/whatsapp/templates/manage-templates#why-was-my-template-rejected).
</Accordion>
<Accordion title="Do carousels work on WhatsApp Web?">
Yes. Customers can see and scroll carousel messages on WhatsApp Web and on mobile.
</Accordion>
</AccordionGroup>
