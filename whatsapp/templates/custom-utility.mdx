> **Who can use this?**
>
> * Owners, Admins, and roles with WhatsApp Templates access.
> * A connected WhatsApp channel is required.

Use **Custom utility** when the message is tied to something the customer already did: an order, an appointment, a delivery.

Do not put a discount, a sale, or "limited time" copy here. Meta will reject it, or recategorise it as Marketing and bill it that way. Skip **Coupon code**. You do not need a STOP footer.

## Plan Availability

Available on all Gallabox plans. Billed as a Utility template. What is free or charged depends on the 24-hour window and the October 1, 2026 change. See [WhatsApp pricing](/pricing-and-billing/whatsapp-pricing/overview).

## Create the template

Go to **WhatsApp → Templates**, click **Create New Template**, and pick **Custom utility**. Name it, pick the **Channel** and **Language**.

Write the **Message body**. Add a header or buttons if you need them. Run **Smart check**, then click **Submit for approval**.

The editor is the same screen as [Custom marketing](/whatsapp/templates/custom-marketing). Use that page for header options, buttons, and [variables](/whatsapp/templates/custom-marketing#variables). For a location pin, see [Location header](/whatsapp/templates/custom-marketing#location-header).

To duplicate, test, or send after approval, see [Manage templates](/whatsapp/templates/manage-templates#after-approval).

Need to take payment in WhatsApp instead? That is **Payment utility**. See [WhatsApp Payments](/whatsapp/payments).

## Smart check

**Smart check** is only on Utility. It sits at the top of the editor. It tells you how likely Meta is to keep this as Utility, before you submit.

1. Write the body.
2. Click **Smart check**.
3. Read the confidence score.

| Confidence | Score | What to do |
| --- | --- | --- |
| **High** | Above 80 | Safe to submit |
| **Medium** | 26 to 80 | Read the reasoning. Use the suggested rewrite if it still sounds transactional |
| **Low** | 25 or below | Remove offer language, or switch Category to Custom marketing |

Smart check is a guide, not a guarantee. Meta still reviews the template.

If you used **AI Rewrite**, run Smart check after, not before. A rewrite can drift into promotional language.

## FAQs

<AccordionGroup>
<Accordion title="Why does Smart check say Low when this is clearly transactional?">
Words like "offer", "exclusive", "limited time", or "discount" look like Marketing to Meta. Use the reasoning Smart check returns. Replace those phrases or remove them.
</Accordion>
<Accordion title="Can I add a coupon?">
Not on Custom utility. A promo code belongs on [Custom marketing](/whatsapp/templates/custom-marketing#coupon-code) or a [Limited Time Offer](/whatsapp/templates/limited-time-offer).
</Accordion>
<Accordion title="Can I pick a new location each time I send?">
No. Duplicate the template and change the pin. See [Location header](/whatsapp/templates/custom-marketing#location-header).
</Accordion>
</AccordionGroup>
