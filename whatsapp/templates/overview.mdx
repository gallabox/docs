> **Who can use this?**
>
> * Owners, Admins, and roles with WhatsApp Templates access.
> * A connected WhatsApp channel is required before the Templates page can be used.

## What are template messages

You cannot start a WhatsApp conversation with a free-typed message. Meta only lets you reach out with a template it has already approved. Gallabox submits that template for you.

You can type freely in the inbox only within 24 hours of the customer's last message. Broadcasts and sequences always use an approved template.

Pick the type that matches **Category** in **Create New Template**. Each name below is that dropdown option.

<Info>

Template messages are charged per send by category. See [Message Credits](/pricing-and-billing/message-credits).

</Info>

## Plan Availability

Available on all Gallabox plans.

## Pick a type

Click a card. That page is the how-to. To list, sync, duplicate, or test templates you already have, use [Manage templates](/whatsapp/templates/manage-templates).

### Marketing

Meta bills these as Marketing. Keep a STOP line on Custom marketing. Carousel and Limited Time Offer have no footer.

<Columns cols="2">
  <Card title="Custom marketing" href="/whatsapp/templates/custom-marketing">
    Offers and announcements. Media, a location pin, a coupon button, a website button, or a form.
  </Card>
  <Card title="Carousel" href="/whatsapp/templates/carousel-templates">
    One message, then up to 10 image or video cards.
  </Card>
  <Card title="Limited Time Offer" href="/whatsapp/templates/limited-time-offer">
    A code with a countdown on the customer's phone.
  </Card>
  <Card title="Product marketing" href="/whatsapp/templates/product-marketing">
    Your catalogue, or a curated set of products.
  </Card>
</Columns>

### Utility

Do not put a discount in Utility. Meta will reject it, or recategorise it as Marketing.

<Columns cols="2">
  <Card title="Custom utility" href="/whatsapp/templates/custom-utility">
    Order updates, appointments, delivery notices. Tied to something the customer already did. Run Smart check before you submit.
  </Card>
  <Card title="Payment utility" href="/whatsapp/payments">
    Ask the customer to pay in WhatsApp. Needs a payment gateway on that channel. Create it here. Send it from a chat.
  </Card>
</Columns>

### Authentication

<Card title="Authentication template" href="/whatsapp/templates/authentication">
  OTPs and verification codes. WhatsApp writes the body. You pick Zero-tap Autofill, One-tap Autofill, or Copy Code.
</Card>

## Not in Category

These are easy to mix up with Meta's specialty list. They are not extra dropdown types.

* **Coupon** is a button on [Custom marketing](/whatsapp/templates/custom-marketing#coupon-code), not its own type.
* **Location** is a header on [Custom marketing](/whatsapp/templates/custom-marketing#location-header) and [Custom utility](/whatsapp/templates/custom-utility).
* **Call permission** is created for you when [WhatsApp Calling](/whatsapp/calling/overview) is on. Send it from a chat. See [Outgoing calls](/whatsapp/calling/outgoing-calls).
