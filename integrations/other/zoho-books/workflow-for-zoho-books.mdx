## Send Invoice Notification Workflow

1. Click on "Use" beside the **Send Invoice** Notification Workflow. 

<Frame>
  <video src="/images/send-invoice-workflow.mp4" autoPlay loop muted playsInline controls className="w-full aspect-video" />
</Frame>

2. Click on "**Choose Template Message**" to open the template library for  you to select the template.  To choose the Template you would like to share with the customers, click **Use** above the chosen template as shown in the picture below.

<Frame>
  <video src="/images/template-message.mp4" autoPlay loop muted playsInline controls className="w-full aspect-video" />
</Frame>

3. Once you have selected the template, the next step is to map the variables in the templates and click on **Done**. 

<Frame>
  <video src="/images/map-the-variables.mp4" autoPlay loop muted playsInline controls className="w-full aspect-video" />
</Frame>

<Info>

For the Media URL, variable _**Invoice Pdf**_ has to be mapped and for Media Name, variable I_**nvoice number**_ has to be mapped. 

</Info>

4. If you would like to Add Action for this Workflow, click on "**+Add Action**" and choose the _Action Type_ from the dropdown, and select the operation - _Append_, or _Add if Empty_. 

<Frame>
  <video src="/images/add-action-send-invoice.mp4" autoPlay loop muted playsInline controls className="w-full aspect-video" />
</Frame>

5. Click on update workflow as the last step.

<Frame>
  <video src="/images/save-send-invoice-workflow.mp4" autoPlay loop muted playsInline controls className="w-full aspect-video" />
</Frame>
