### ShipRocket API Configuration

1. Sign in to your ShipRocket Account. Click On **Settings => API => Configure** or you can go directly to this link - [https://app.shiprocket.in/api-user](https://app.shiprocket.in/api-user). 

<Frame>
  <video src="/images/integration-shiprocket.mp4" autoPlay loop muted playsInline controls className="w-full aspect-video" />
</Frame>

2. Click on **Create an API user,** in the pop-up menu, fill in the **email** (this email should be different from that of the one used to register to ShipRocket).

<Frame>
  <video src="/images/api-configure-shiprocket.mp4" autoPlay loop muted playsInline controls className="w-full aspect-video" />
</Frame>

### ShipRocket Configuration Steps

1. Go to **Integrations** in the left navigation of your Gallabox account. Hover over **ShipRocket** Integration from the available applications and click on the Connect button.

<Frame caption="Integrations in Gallabox">
  <video src="/images/gallabox-integartion-shiprocket.mp4" autoPlay loop muted playsInline controls className="w-full aspect-video" />
</Frame>

2. Once you click on ShipRocket, click on **Connect.** You will be prompted to add Integration Name, and Email & Password created in your ShipRocket account. After pasting click on Submit. 

<Frame caption="ShipRocket Integration in Gallabox">
  <video src="/images/gallabox-shiprocket.mp4" autoPlay loop muted playsInline controls className="w-full aspect-video" />
</Frame>

3. Once you have entered the API Email & Password, it will redirect you to enter the configuration in Gallabox. 

<Frame caption="Configuring the Integration">
  <video src="/images/shiprocket-configuration-gallabox.mp4" autoPlay loop muted playsInline controls className="w-full aspect-video" />
</Frame>

4. You have to select the channel Name and click on Update Configuration. 

<Frame>
  <video src="/images/shiprocket-channel-selection.mp4" autoPlay loop muted playsInline controls className="w-full aspect-video" />
</Frame>

### ShipRocket Webhook Setup

You have to add the webhook generated while configuring ShipRocket in your Gallabox Account. 

1. Jump to your ShipRocket dashboard. Select "**Settings**" and then "**API".** Under API select **Webhook.** 

<Frame>
  <video src="/images/shiprocket-url.mp4" autoPlay loop muted playsInline controls className="w-full aspect-video" />
</Frame>

2. Paste the Webhook URL and the Webhook Secret from your Gallabox account as shown in the below GIF.

<Frame caption="Adding the Webhook URL and Webhook Secret">
  <video src="/images/webhook-settings-webhook.mp4" autoPlay loop muted playsInline controls className="w-full aspect-video" />
</Frame>

3. Test and Save the Webhook. 

<Frame>
  <video src="/images/save-webhook-in-shiprocket.mp4" autoPlay loop muted playsInline controls className="w-full aspect-video" />
</Frame>

Once you have done this, your ShipRocket Integration will be connected with Gallabox.
